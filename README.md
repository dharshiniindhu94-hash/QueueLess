# QueueLess – Smart Clinic Queue Management System

## Project Description
QueueLess is a Django-based web application designed to simplify queue management in clinics. It helps patients manage appointments and reduces waiting time through a digital queue system.

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Main Features
- User Registration and Login
- Clinic Management
- Doctor Dashboard
- Patient Queue Management
- Appointment Management
- Queue Status Tracking
- Notifications

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/dharshiniindhu94-hash/QueueLess.git
   ```

2. Navigate to the project folder:
   ```bash
   cd QueueLess
   ```

3. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

4. Install dependencies:
   ```bash
   pip install django
   ```

5. Run database migrations:
   ```bash
   python manage.py migrate
   ```

6. Start the development server:
   ```bash
   python manage.py runserver
   ```

7. Open your browser and visit:
   `http://127.0.0.1:8000/`
